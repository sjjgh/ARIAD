## 实验设置

**任务。** 受控的 teacher–student 合成任务：学生能否用 top-k 稀疏注意力（Exact 或 ARIAD 维护的近似邻居）学到 teacher 的路由，并与 Dense 比较输出质量；同时估算算力。

**数据。** N/16 个单位球上的随机簇中心（64 维），每簇 16 个点，加标准差 0.05 的高斯抖动后逐点 L2 归一化，得到 G ∈ R^{N×64}。独立的高斯值 V ∈ R^{N×64}。学生输入 X=[G | V]（128 维），逐特征标准化。N ∈ {1008, 2000, 5008, 10000, 20000}；每个 N 用**一份固定数据**（数据 seed 0），三个训练 seed 只改变初始化和 ARIAD 的随机图/候选采样，不改数据。

**Teacher。** 打分 S_ij = g_i·g_j / √64（自身置 −∞），**没有**全局均值/方差标准化；logits = S/τ，τ=0.01。稀疏聚合：只保留每行 S 的 top-32，在其中做 softmax，其余权重为 0：

y_i = Σ_{j∈T_i} softmax_{T_i}(S_ij/τ) · v_j，T_i = S 的第 i 行 top-32。

数据生成时的检查：有效支持 1/Σa² 在 N=1008、2000、5008、10000、20000 上分别为 14.14、14.18、14.20、14.22、14.25，top-32 注意力质量均为 1.0000，说明 teacher 是尖锐的 top-k 聚合。

**学生（双空间）。** q = X·Wq，k = X·Wk（各 64 维，Wq 与 Wk **独立**，Xavier 初始化），打分 q·k/√64。值 v 取 X 中 V 那一块的**恒等映射**（Wv 固定、不训练，见下）。方法：

- **Dense**：对全部非自身节点做 softmax 聚合。它的 top-32 只用作诊断（计算 teacher match）。
- **Exact top-k**：每步用当前 q、k 精确重算 top-32，聚合方式与 ARIAD 相同。
- **ARIAD**：维护三张图：QQ 图（Q 空间近邻）、KK 图（K 空间近邻）和 QK 图（每个 query 的 key 集合，即注意力实际使用的 32 个 key）。图从随机初始化开始，不使用 teacher 或精确邻居。每步只在训练前向里刷新一次，评估时复用该图（所以 current-graph recall 含一步更新的滞后）。

**训练。** 全批量 Adam，学习率 1e-2，无 weight decay，恒定学习率，500 步（1 步 = 1 epoch），3 个训练 seed（0, 1, 2）。同一 seed 下三种方法共享初始权重。

**指标。**

- **MSE**：每次更新之后，在同一批训练节点上评估（eval 模式），不是留出集。
- **Teacher match@32**：学生邻居集合与 teacher top-32 集合 T_i 的平均重合比例。Dense 用其学到的打分的 top-32。
- **Current-graph recall**（补充表）：ARIAD 维护的图与它自己当前 q、k 下精确 top-32 的重合度。为节省计算，在随机抽取的 1000 行上计算。
- **邻居替换率**（Fig. 2a）：100·[1 − (1/N)·Σ_i |H_t(i) ∩ H_{t−1}(i)| / 32]，H_t 是各方法自己的 32 邻居图。Dense 用其 top-32，Exact 用其精确 top-32 图，ARIAD 用其维护的 QK 图。

**算力模型（Fig. 1）。** 与论文同样的形式，改为双空间：

F = 6·N·d_in·(2·d_z + d_v) + 6·P_attn·(d_z + d_v) + 2·P_search·d_z

其中 d_in=128，d_z=d_v=64（三个投影 Wq、Wk、Wv）。(P_attn, P_search) 为 Dense (N², 0)、Exact (N·k, N²)、ARIAD (N·k, N·C)，k=32。前向/反向按 3 倍前向计，一次乘加记 2 FLOPs。ARIAD 每行每步打分的候选槽数 C=480，由配置直接数出（含去重和自身掩蔽之前的重复项）：

- QQ 图：k + c_o2 + c_i1 = 64 + 80 + 32 = 176
- KK 图：64 + 80 + 32 = 176
- QK 图：k_final + b_kF + b_qF + b_kR = 32 + 32 + 32 + 32 = 128

这是成本模型估算，不是实测；不含 softmax、top-k、去重、gather/scatter 和显存访问。

## 结果

### Table 1（N ↑；MSE 单位 ×10⁻⁴；3 个 seed 的均值 ± 样本标准差；"<" 表示标准差低于显示精度）

|---:|---:|---:|---:|---:|---:|---:|
| 1,008 | 7.80±0.02 | 7.81±0.01 | 7.88±0.03 | 0.7046±0.0020 | 0.6847±0.0118 | 0.6899±0.0081 |
| 2,000 | 5.31±0.04 | 5.40±0.08 | 5.45±0.04 | 0.8793±0.0041 | 0.8587±0.0080 | 0.8556±0.0045 |
| 5,008 | 1.65±<0.01 | 1.52±<0.01 | 1.52±<0.01 | 0.9435±<0.0001 | 0.9437±<0.0001 | 0.9436±<0.0001 |
| 10,000 | 1.40±<0.01 | 1.07±<0.01 | 1.07±<0.01 | 0.9551±<0.0001 | 0.9554±<0.0001 | 0.9550±<0.0001 |
| 20,000 | 1.30±<0.01 | 0.52±<0.01 | 0.52±<0.01 | 0.9672±<0.0001 | 0.9700±<0.0001 | 0.9680±0.0009 |

补充（`table1_extra.md`）：

| N | ARIAD current-graph recall@32 | ARIAD − Exact 的成对 MSE 变化（各 seed） | ARIAD − Exact 的 match@32 |
|---:|---:|---:|---:|
| 1,008 | 0.9981 | +0.97%（+0.55%, +1.19%, +1.17%） | +0.0052 |
| 2,000 | 0.9970 | +0.86%（+1.37%, −1.53%, +2.72%） | −0.0031 |
| 5,008 | 0.9995 | 0.00% | −0.0001 |
| 10,000 | 0.9989 | 0.00% | −0.0004 |
| 20,000 | 0.9961 | +0.01%（+0.00%, +0.01%, +0.01%） | −0.0020 |

读法：

- **ARIAD 与 Exact top-k 几乎重合。** N ≥ 5008 时两者 MSE 的成对差在 0.01% 以内；N ≤ 2000 时 MSE 差在 3% 以内（N=2000 的三个 seed 里有一个 ARIAD 更低）。match@32 的差不超过 0.006（最大是 N=1008 的 +0.0052）。ARIAD 的图与其自身精确 top-32 的重合度在所有 N 上都不低于 0.996，包括 N=20000。
- **在这个设定里，ARIAD 没有随 N 增大而变差。** 论文单空间在 N=20000 处 ARIAD 相对 Exact 的 MSE 升高、图召回下降；这里没有出现。但这里的搜索预算更大（每行每步 480 个候选槽，三张图），不能据此推断固定小预算下的表现。
- **Dense 的 MSE 在 N ≥ 5008 时更高**（N=20000 时 1.30 对 0.52），方向与论文一致；在 N ≤ 2000 时 Dense 与另两者相当（N=1008、2000 略低）。teacher 本身是 top-32 稀疏聚合，这个比较对稀疏学生有结构上的优势，不能据此说 Dense 有不可避免的误差下限。
- **teacher match@32 随 N 上升**，N=20000 时三者都在 0.967–0.970。Dense 的 match 只是诊断值。
- **N ≥ 5008 时标准差小于显示精度。** 三个 seed 的初始化不同（各 seed 的最终 recall 在第 4 位小数之后才不同），但都收敛到几乎同一个解，所以方差很小。这不代表结果对初始化"不敏感"的一般结论，因为每个 N 只有一份数据。
- N=1008、2000 时 seed 间的方差明显更大（match 标准差 0.004–0.012）。这里没有保存训练曲线，未检查它们是否已收敛。

### Fig. 1：估算算力 vs N

![fig1](fig1_cost.png)

- N=20000 时估算成本：Dense 310.15、Exact top-k 54.64、ARIAD 4.67 GFLOPs；ARIAD 约为 Exact 的 8.5%。
- 五个 N 上的 log-log 拟合斜率：Dense 1.95、Exact 1.74、ARIAD 1.00。ARIAD 的模型算力对 N 是线性的。
- 这是成本模型，不代表端到端运行时间或墙钟加速；稀疏操作在实际硬件上可能比优化后的稠密 GEMM 慢。

### Fig. 2：训练动态（N=10000，k=32，seed 0）

![fig2](fig2_dynamics.png)

三种方法都是同一 seed 0 的训练运行，每个 epoch 都做一次全部 N 行的审计（不计入训练成本）。

- **(a) 邻居替换率。** 三者早期都有大量替换，然后逐渐下降到接近 0（200 epoch 时约 0.1%，500 epoch 时 0.00%）。ARIAD 早期替换更多：epoch 2 时 51.4%（Dense、Exact 约 21%），因为它从随机图出发。之后 Exact 在 epoch 26 出现一个局部峰值（16.9%），ARIAD 在 epoch 50 出现一个局部峰值（12.9%）；两者都发生在各自 MSE 骤降的位置，ARIAD 的更晚。这些曲线各自描述自己的图，替换率相近并不说明它们的邻居集合一致。
- **(b) MSE。** 在 epoch 1 和每 10 个 epoch 采样。MSE 首次低于 1e-2 的 epoch：Dense 31，Exact 31，ARIAD 56；低于 1e-3：73、74、89。约 150 epoch 之后 ARIAD 与 Exact 重合。500 epoch 时 MSE：Dense 1.40e-4，Exact 1.07e-4，ARIAD 1.07e-4。ARIAD 从随机图起步，开始阶段落后，之后追平。这是单次轨迹，不能说明收敛速度的优势或劣势。

## 与论文单空间设定的差异

| | 论文单空间 | 本实验（双空间） |
|---|---|---|
| 学生 | Z=XWz，V̂=XWv，得分 z·z/√64 | q=XWq，k=XWk（独立），得分 q·k/√64；值固定为 X 中 V 块的恒等映射 |
| Teacher 打分 | (g·g − μ)/σ，μ、σ 是全局统计量 | g·g/√64，无全局标准化 |
| τ、抖动 | τ=0.5，抖动 0.10 | τ=0.01，抖动 0.05（固定缩放下点积很小，需要小 τ 才能让 teacher 尖锐，已核对有效支持和 top-32 质量） |
| ARIAD | 单张图，C_scored=144 | 三张图（QQ、KK、QK），共 480 个候选槽/行/步 |
| 算力模型 | 6N·d_in·(d_z+d_v)+… | 三个投影，d_in·(2d_z+d_v)；搜索项按上面的 480 计 |

其余相同：N 列表、簇大小 16、k=32、稀疏 top-32 teacher、全批量 Adam、lr 1e-2、无 weight decay、500 步、3 个成对训练 seed、每个 N 一份固定数据。

### 为什么 Wv 固定

Wv 可学习时，独立 Wq/Wk 的学生学不到路由：在同一个管线里，Dense、Exact、ARIAD 三种方法的 recall 都停在随机水平（约 0.016）。诊断显示，此时落在簇内伙伴上的注意力质量只有 0.004（随机），注意力散在约 200 个 key 上，靠加权组合回归目标，MSE 却能降到 0.019；Wv 始终没有对齐到恒等映射。Wv 固定成 V 的恒等映射后，独立 Wq/Wk 立即能学。tied（Wq=Wk）不受影响。机制解释（路由和 Wv 互相等待）与观察一致，但我没有做因果干预实验。因此本实验是"值已知"的设定，和论文里 Wv 可学的学生不同。

### 数据生成器的改动（不影响结果的实现说明）

- `teacher_scale="fixed"`：新增的 teacher 打分选项（默认仍是论文的 `global_standardize`）。
- gate 检查（oracle recall 与扰动稳定性）改为只对前 min(k_eval, 簇大小−1) 个槽位检查：top-32 里超出簇内伙伴（15 个）的部分是簇外点，排序在任何扰动下都不稳定，按 32 整体计算会必然失败。
- 行内 top-k 改成按行分块（结果不变），否则 N=20000 时生成数据会因为一个 3GB 的 int64 临时数组内存不足。
- 训练评估时抽样行用独立的随机数生成器，评估频率不会改变训练的随机数流。
