# Experimental write-up sources

These files preserve the research content used to prepare the repository README:

- [single_space.tex](single_space.tex): experiment section extracted from the author's `main.tex`.
- [dual_space.tex](dual_space.tex): independent-query/key experiment section.
- [single_space_suppl.tex](single_space_suppl.tex): arithmetic model and implementation details.
- [tables/](tables/): original mean/std result tables.
- [figures/](figures/): original PDF figures.

These are archival LaTeX fragments, not a standalone compilable manuscript.
References retain the original manuscript paths and labels. Conference-template
title, placeholder authors, review identifiers, style files, and example sections
are omitted. This repository makes no claim of conference acceptance.

The root README presents the experiments in browsable Markdown; numerical
records and regeneration scripts live alongside each experiment's code.
